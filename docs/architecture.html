01 · Runtime architecture

Three deployments, one durable system

The browser talks to the Next.js product surface. NestJS owns auth and transactional APIs. The separately deployed Eve agent owns every judgment. Postgres is both system of record and the durable handoff between them.

Product view

One workspace, many surfaces

Reps work in dashboard, companies, contacts, deals, outreach, tasks, settings, and Agent. The workspace slug is cosmetic routing; the data model is deliberately single tenant.

Engineering view

The database is the handoff

The API records that work is needed by inserting an AgentTask. The agent leases that row later, so browser, API, or agent restarts do not lose the intent.

Trust boundary

Signed, scoped agent access

The app strips the session cookie and mints a two-minute token naming the rep and optional record. Record context never rides inside the chat message.

02 · Durable work loop

Research continues after the tab closes

Every trigger becomes a leased row. Work that needs no judgment takes a fast direct lane; the rest becomes a durable Eve session that consults only available capabilities and writes through an evidence gate.

Why it feels autonomous

The schedule decides nothing

dispatch.ts only leases what is due. Priority and dueAt live with the work, so follow-ups remain explainable and recoverable.

Human safety

Evidence, never model confidence

Tools report an observed method. The evidence ledger determines whether a field can be applied automatically or must be proposed to a rep.

Capability model

Missing providers remove reach

No optional key may crash the product. CRM history remains available; absent vendors return “not configured” before a call is attempted.

03 · Data architecture

One Postgres, eight durable domains

Prisma keeps product records, imported communication, agent state, auth, settings, and operational ledgers in one database. The grouping below is conceptual; all tables share the same transactional store.

Product model

Companies organize the commercial graph

Contacts belong to companies, deals belong to companies, and contacts join deals through explicit roles. Activities create the common timeline across all three.

Financial truth

Original and reporting amounts coexist

amount + currency is what the customer pays. A frozen rate produces baseAmount, the only value totals and charts may sum.

Data hygiene

Imported addresses are filtered

Internal users, suppressed identities, machines, and automated addresses are removed before Gmail or Calendar can create CRM people.

04 · Code and delivery

A Bun/Turborepo with explicit boundaries

Three applications compile and deploy independently but consume the same workspace packages. The API’s tRPC router type is generated locally and committed so the Next.js app remains type-safe without regenerating in production.

Shared boundaries

Packages define the platform

  • packages/ui: all shared shadcn components and theme
  • packages/auth: Better Auth, allow-list, permissions, SSO
  • packages/db: Prisma client, schema helpers, safe fetch and Blob
  • packages/env and telemetry: root config and allowlisted reporting

Release flow

Every branch is reviewable

A pushed branch opens a draft PR. Ready PRs run types, lint, tests, and title validation. Main feeds release-please; merging the release PR tags a version and advances the release branch.

Local parity

Same processes, local endpoints

bun run dev runs app :3000, API :3001, agent :2000, with Docker Postgres on :5432.

Invariant 01

Intelligence lives in apps/agent

The API may record an event or task, but it never researches, enriches, scores, summarizes, or matches identity. This keeps judgment in one auditable implementation.

Invariant 02

Truth is evidence-scoped

Strong observed evidence can update a record. Weaker evidence becomes a proposal. Human-entered values are never silently overwritten.

Invariant 03

Optional means non-fatal

Missing Redis, Blob, search, LinkedIn, Context, or model credentials remove capability; they do not prevent the CRM from booting.
